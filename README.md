# HomeOps

Living property record — dashboard, digital twin, asset passports, records timeline, service request flow.

Standard Next.js app. No platform-specific auth, hosting bindings, or build harness — runs anywhere Node.js runs.

## Run locally
npm install
npm run dev

## Build
npm run build
npm start

## Deploy
Push to GitHub, connect the repo to Railway or Vercel. No special config needed.
